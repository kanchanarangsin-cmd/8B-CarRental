## วิธีเปิดด้วย XAMPP

1. นำโฟลเดอร์ `50` ไปไว้ใน `C:\xampp\htdocs\`
   หากมี `C:\xampp\htdocs\50` รุ่นเก่าอยู่ ให้ปิดหน้าเว็บ แล้วแทนที่ไฟล์ในโฟลเดอร์นั้นด้วยไฟล์จาก ZIP ฉบับนี้ (สำรองของเดิมไว้ก่อน) การดาวน์โหลด ZIP อย่างเดียวไม่เปลี่ยนไฟล์ที่ XAMPP กำลังใช้
2. เปิด Apache และ MySQL ใน XAMPP Control Panel
3. เปิด phpMyAdmin แล้วสร้างฐานข้อมูลชื่อ `car`
4. Import `database_schema.sql` และไฟล์ patch ที่โปรเจกต์เดิมใช้งาน
5. เปิด `http://localhost/50/`
6. ถ้าหน้ารถ/ลูกค้า/พนักงานยังเป็นปุ่มแก้ไขไล่สี ให้กด `Ctrl+F5`; จากนั้นตรวจว่าไฟล์ `pages/cars.php` มี `btn-edit` และโหลด `design_tokens.css?v=dc36a003b825` หากไม่พบแสดงว่ายังเปิดโฟลเดอร์ `50` รุ่นเก่า

หากฐานข้อมูลเดิมของกลุ่มมีข้อมูลครบแล้ว ให้ใช้ฐานข้อมูลเดิมและไม่ต้อง Import ทับ

## จุดที่ต้องทดสอบก่อนอัด

- Analytics: กดหัวข้อทั้ง 5 แล้วตรวจว่า Active และตัวกรองแสดงครั้งละ 1 กลุ่ม
- Analytics: ไม่เลือกค่าแล้วกดค้นหา ต้องแสดง Error ภาษาไทย
